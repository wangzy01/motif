# MoT repository operating rules

1. Treat `docs/MOT_HANDOFF_CURRENT.md` and
   `docs/STAGE512A_FINAL_AUTHORITY.md` as the compact current entry points.
2. Stage512a architecture is frozen. Stage512b-real data, budget, evaluation,
   and launch identities require a separately reviewed proposal.
3. Do not add checkpoints, datasets, outputs, rendered jobs, credentials,
   environment files, launch material, or historical incident trees to Git.
4. Heavy data, checkpoint, storage, or GPU work must use the approved JCC
   workflow and retain immutable evidence.
5. Never infer execution authority from a historical config or reference
   evaluation script.
