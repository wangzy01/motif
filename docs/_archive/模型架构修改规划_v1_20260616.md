## Part A — Day-1 baseline 对齐（先落地、跑稳）

### A1. 生成侧 sandwich norm 〔arch_mot.py，网络结构，最重要〕

**v3 要求**：仅生成/噪声 token 的生成分支，在 attn / MLP 子层**输出处**各加一个 RMSNorm 再残差相加（`x_gen += RMSNorm(sublayer(...))`）；冻结理解侧（pre-norm Qwen3-VL）不碰；初始权重=1、非恒等；留 config 开关，早期不稳再关。

**当前**：[MoTDecoderLayer.forward](../../mot_code/mot_pilot_v1/networks/arch_mot.py) 是纯 pre-norm，无输出 norm。

**源码核对**：
- Cosmos3 MoT decoder layer **也是纯 pre-norm，没有 sandwich norm**（已确认）。
- i1 的 sandwich norm 在 AdaLN+gate 语境（`x += gate · Norm(sublayer)`）。
- → 我们要的是**无 gate、无 AdaLN、weight=1** 版本，等于按 v3 spec **新写**，参考 Z-Image / CogView 产线语义。

**改动点**：
1. `MoTDecoderLayer.__init__` 新增两个 hidden 维 `Qwen3VLTextRMSNorm(hidden, eps=config.rms_norm_eps)`，命名 **`attn_out_norm_moe_gen`** / **`mlp_out_norm_moe_gen`**。
   - ⚠️ **必须带 `_moe_gen` 后缀**：这样 [is_trainable_param_name](../../mot_code/mot_pilot_v1/networks/arch_mot.py) 自动判为可训练；[_load_und_weights](../../mot_code/mot_pilot_v1/networks/model_mot.py) 的 `expected_und`（"非 `_moe_gen` 且非 proj/time_embed"）自动排除它；`init_generation_tower_from_und` 不会复制它（它只复制显式列出的模块）。默认 RMSNorm weight=1 正好满足"初始权重=1"。
   - ❌ 不要用 `*sandwich_norm_gen`（不带 `_moe_gen`）的命名：会被 `_load_und_weights` 误判为"必须从 und checkpoint 加载"，checkpoint 里没有 → assert 直接挂，且要同时改三处函数。
2. `MoTDecoderLayer.forward` 改为（仅生成支加 norm，und 支保持原样）：
   ```python
   a_und, a_gen = self.self_attn(self.input_layernorm(h_und),
                                 self.input_layernorm_moe_gen(h_gen),
                                 position_embeddings, attn_mask)
   h_und = h_und + a_und                              # und 不变
   h_gen = h_gen + (self.attn_out_norm_moe_gen(a_gen) if self.sandwich_norm else a_gen)
   h_und = h_und + self.mlp(self.post_attention_layernorm(h_und))   # und 不变
   m_gen = self.mlp_moe_gen(self.post_attention_layernorm_moe_gen(h_gen))
   h_gen = h_gen + (self.mlp_out_norm_moe_gen(m_gen) if self.sandwich_norm else m_gen)
   ```
3. config 开关 `model.sandwich_norm`（默认 `true`）→ `MoTT2ITransformer.__init__` 透传到每个 `MoTDecoderLayer`。

**验证锚点**（扩 `smoke_real_weights.py` / 新增单测）：
- `sandwich_norm=false` 时 step-0 前向 == 旧实现（数值回归）。
- `attn_out_norm_moe_gen` / `mlp_out_norm_moe_gen` 的 `requires_grad=True`，且不在 und 加载命中集；frozen und 的 q/k/v/o/mlp/ln 仍无梯度。
- und 路 vs HF Qwen3VLTextModel 仍 `max|Δ|=0`（und 未改动）。
- 可训练参数量在 1.416B 基础上小幅增加（28 层 × 2 × hidden 个 RMSNorm 权重）。

### A3. noise shift 改 per-分辨率固定 〔model_mot.py + config，训练阶段〕

**v3**：课程 256→512→1024；256 基本不 shift，512/1024 逐步抬高；乘式 convention 下 1024 起点 ~4、sweep 3.3–5，随最终 VAE 下采样因子调。

**改动点**：
1. [get_sigmas / current_shift](../../mot_code/mot_pilot_v1/networks/model_mot.py)：去掉训练进度 ramp（`shift_start/shift_end/ramp_start_frac/ramp_end_frac`），改为读单一常数 `sigma_sampling.shift`（float）。shift 变换公式不变（`σ' = s·σ/(1+(s-1)σ)`）。
2. `set_train_progress` 保留（仍驱动日志/EMA 进度），但不再驱动 shift。
3. 各阶段取值（已拍板）：
   | 阶段 | image_size | `sigma_sampling.shift` |
   |---|---|---|
   | stage1a-256 | 256 | **1.0**（不 shift） |
   | stage1a-512 | 512 | **2.0**（sweep 起点） |
   | stage2-1024 | 1024 | **4.0**（sweep 3.3–5） |

**convention 陷阱（务必记住）**：i1 的 shift 公式与我们**数学相同**，但**时间轴相反**（i1: t=1 数据/t=0 噪声；我们: σ=1 噪声/σ=0 数据）。所以 i1 配置里的 `train_timestep_shift`(256/512=0、1024=0.3) **不能直接照搬**；v3 已把它映射到我们 convention 下的等价值（1024≈4），上表即按此填。最终随 VAE 下采样因子再核。

## Part B — i1 消融增量（baseline 同时搭 config 骨架，默认关、zero-init、step-0 等价）

> 共同原则：默认 config 关、初始严格等价 baseline、绝不污染冻结塔；先 256 便宜消融验证，过线再进主训。排期 ①→②→③→④。
> 本轮按决策⑥：**搭 config 开关 + zero-init 接口骨架**（不必跑通完整训练逻辑，但要保证默认关时 step-0 与 baseline 逐位等价）。

### B1. 文本 adapter（消融第 1 项）

- **新模块 `TextAdapter`**（arch_mot.py）：2 层双向 transformer，宽 2048，RMSNorm + QK-norm + SwiGLU，**不加 RoPE**，**末层投影 zero-init**（起点≈原始末层文本，纯增量）。⚠️ **参数量更正**（2026-06-17 实测真 config）：TextAdapter 本体 **~113M**（非原写 ~35M）；叠加下条逐层 text K/V ~117M，**B1 臂总额外 ~231M ≈ 16% 生成塔**（远超原"<2.5%"）。
- **数据流**：frozen und 末层 `H_t [B,L_t,2048]` → `TextAdapter` → `T_cond`；生成塔新增可训练 **`text_k_proj_moe_gen` / `text_v_proj_moe_gen`** attend `T_cond`；此臂下生成塔**不再逐层看原始 und**（理解分支仍用原始 H_t，互不污染）。
- **mask 影响**：需扩展注意力，让生成 token 额外 attend 一段独立 text-cond KV（与逐层 und KV 由 config 选臂互斥）。
- **config**：`model.text_adapter.{enabled(默认false), num_layers=2, bidirectional=true, rope=false}`。
- **消融主轴（已按决策⑨单列中间对照臂）**：
  `{无 adapter}` vs **`{固定末层文本、无 adapter}`（中间对照臂）** vs `{A·因果}` vs `{A·双向}`，RoPE 全程关。
  → 中间对照臂把"逐层 und→固定末层文本"的拓扑改动 与 "加 adapter" 两件事**分开归因**（覆盖 v3 原"不单列、省算力"的决定）。
- **i1 源码差异**：i1 adapter 默认 1 层、有 null-embed dropout、确实无 RoPE，但**无 zero-init**；我们的 zero-init 是 v3 自加的"严格等价 baseline"保险。
- **兜底 Variant B**（A 不明显再退）：逐生成层给文本 K/V 加 zero-init LoRA 式 ΔK/ΔV。

### B2. 生成侧 long skip（LS-A，消融第 2 项）

- **机制（仅生成 token）**：前半层缓存生成 token 激活，后半对称层（i ↔ L+1−i，L=28 → ~14 条）在生成支 input-norm 之前融合：
  `x_gen += gate · ZeroInitLinear(concat(RMSNorm(x_gen), RMSNorm(skip)))`，**gate zero-init → step-0 严格等价无 skip**。
- **落点**：`MoTT2ITransformer.forward` 层循环维护 skip 缓存（只缓存生成 token，省显存、绕开 AR/KV-cache，非对称 mask 保证不回流污染冻结侧）。
- **config**：`model.long_skip.{enabled(默认false), mode: A_full|B_outer}`。
- **消融（≤3 组）**：baseline / LS-A 对称全连 / LS-B 只连最外 ~1/3 层。go/no-go：256 稳定涨 → 进 512。
- **i1 源码差异**：i1 是 U-ViT in/mid/out + `skip_linear(concat(x, skip))`，**无 gate、无 zero-init、concat 前不分别 norm**；我们三处都加固（更稳、保 baseline）。

### B3. 去噪声条件（消融第 3 项，最便宜）

- **机制**：把 [MoTT2ITransformer.forward](../../mot_code/mot_pilot_v1/networks/arch_mot.py) 的 `h_gen = proj_in(img) + t_emb` 做成可关。
- **config**：`model.noise_condition`（默认 `true`=加性注入一次；`false`=彻底删，省参数）。对照"加性 vs 彻底删，确认不掉分再决定是否删"。
- **不引入 AdaLN-zero**（与 i1/现状都背离）。

### B4. 绝对 sinusoidal 位置（低优先，消融第 4 项）

- **机制**：仅生成 token 加 `α·Sin2D(h,w)`，α zero-init，**AR 分桶感知**（不照搬 i1 的方图插值）；只在文字渲染/精确版面成明确目标时跑；不动文本/理解侧。
- **config**：`model.abs_sincos.enabled`（默认 false）。主线仍以 Interleaved-3D-MRoPE 为承重墙。
- **i1 源码**：有标准 2D sincos（含分辨率插值 components.py），我们要 AR 分桶版。

## Part D — 明确「不改」项（防止误动）

- **不改数据集读取 / dataio 展示逻辑**（本轮范围外）。
- **不改 attention mask 方向**：当前 text causal / text 不看 image / image 看有效 text + 全部 image 已正确（与 v3、06-11 拍板一致）。
- **不引入 content-only / prompt-content mask，不切 template prefix（无 drop-prefix）**：模板 token 对噪声图可见，维持现状。
- **不把 σ 改成 1−σ 送模型**：当前 timestep embedding 接收 noise weight σ 本身。
- **不改 loss**：rectified-flow v-pred，`x_t=(1-σ)x0+σ·noise`，target=`noise-x0`，纯 MSE。
- **不改 proj_out 零初始化**。
- **不加 clean-image / ViT 理解路径**（纯 T2I 这轮不需要）。
- **不引入 AdaLN-Zero**。
- QK-norm 维持 Qwen3 自带，不动。
