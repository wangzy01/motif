# Evaluation protocols

Reusable implementations live in `evaluation/benchmarks/` and
`evaluation/runners/`; the final Stage512a protocol snapshot lives in
`evaluation/reference/stage512a_final_20260728/`.

Internal DPG-Qwen measurements are not directly comparable with official
DPG/mPLUG results. Any public comparison must report resolution, steps, CFG,
prompt text, prompt rewriting, scorer identity, and aggregation rules.
