## 1. 当前默认网络架构（Day-1 baseline，逐组件）

代码：[networks/arch_mot.py](../networks/arch_mot.py)（backbone）+ [networks/model_mot.py](../networks/model_mot.py)（包装/loss/采样）。

### 1.1 双路 MoT backbone
- **理解路 und（冻结）**：`Qwen3-VL-2B-Instruct` 文本塔 = `embed_tokens` + 28 层 + final `norm`。hidden 2048 / 28 层 / 16 头 / KV 8（GQA）/ head_dim 128 / mrope_section [24,20,20] interleaved。全程 `requires_grad=False`。
- **生成路 gen（可训）**：逐层复制 und 初始化（`init_generation_tower_from_und`），权重独立，命名带 `_moe_gen` 后缀。
- **MoT 权重划分 = Cosmos3**：**分流** = LayerNorm + MLP + QKV/O 投影（+QK-norm）；**共享** = 注意力运算本身 + RoPE + 同一条序列。即 und 用 `q/k/v/o_proj`、`mlp`、`input/post_attention_layernorm`、`norm`；gen 用对应 `*_moe_gen`。
- **可训练集**（`is_trainable_param_name`）= 名字含 `_moe_gen` **或** `proj_in/proj_out/time_embed` 前缀。其余（embed、und 全部、final norm、rotary）冻结。实测 **trainable 1.416B / frozen 1.721B / total 3.135B**。

### 1.2 注意力 + mask（`build_t2i_attention_mask`）
batched padded `[B,S]` + SDPA bool mask（**非** packed sequence）。规则：
- 文本→文本：causal ∧ 有效（右 pad 不作 key）；
- 文本→噪声图：**不可见**；
- 噪声图→文本：可见全部有效文本；
- 噪声图→噪声图：bidirectional 全可见。

und 与 gen 拼成一条序列（und 在前、gen 在后）做联合注意力。**GPU 实测 bool-mask SDPA 走 cuDNN 后端**（非 MATH 退化，1.16× flash 天花板）。

### 1.3 位置编码（`build_t2i_position_ids`，Interleaved-3D-MRoPE）
复用 HF `Qwen3VLTextRotaryEmbedding`。文本退化 1D（t=h=w=token 位置）；生成图 t = `text_len + Δ`（Δ=`time_gap`=2048，Cosmos3），h/w 段内从 0 起。

### 1.4 Timestep 注入（`TimestepEmbed`，非 AdaLN-Zero）
σ → `Timesteps(256 sinusoidal)` → MLP(Linear→SiLU→Linear) → **加性 scatter 到噪声 token**（`h_gen = proj_in(img) + t_emb`）。`timestep_multiplier` 只缩放 sinusoidal 输入尺度，默认 **1.0**（= Cosmos3 timestep_scale 0.001 直接喂 σ）。

### 1.5 归一化
- **QK-norm**：Qwen3 自带（und 与 gen 各自的 `q_norm/k_norm(_moe_gen)`），稳 attention logits，不动。
- **生成侧 sandwich norm**（Day-1 baseline，默认开）：仅生成支，在 attn / MLP 子层**输出处**各加一个 hidden 维 RMSNorm 再残差（`x_gen += RMSNorm(sublayer)`）。命名 `attn_out_norm_moe_gen` / `mlp_out_norm_moe_gen`，weight=1（非恒等）。冻结理解侧纯 pre-norm 不碰。定位 = 稳定性保险（Z-Image/CogView 产线）。关掉即逐位退回纯 pre-norm。

### 1.6 VAE（[networks/vae.py](../networks/vae.py) `Flux2VAE`）
FLUX.2 `AutoencoderKLFlux2`（f16c128，权重 `/fsx/models/FLUX.2-klein-4B/vae`）：encode = `ae.encode().sample()` → 2×2 patchify → BN 标准化 → model-space `[B,128,H/16,W/16]`；decode 逆之。**MoT 侧 `patch_size=1`**（VAE 已 16×/128ch，不二次 pack）。还提供 `moments_to_model_space()`，供数据线 offline 缓存原始 VAE moments → 模型侧转 model-space 并重采样 posterior（`prepare_latents` 已接此分支，与在线 encode 同分布）。

### 1.7 文本编码（`encode_text`）
Qwen-Image 式 chat template（默认开，`prompt_template.enabled`）：~41-token 模板 + caption，pad 到 `text_max_length=384`。模板 token 全程作上下文（无 Qwen-Image 那种 encode 后 drop prefix）。

### 1.8 损失 + σ 采样（`forward` / `get_sigmas`）
- **rectified flow v-pred + 纯 MSE**：`x_t=(1-σ)x0+σ·noise`，`target=noise-x0`，loss = `(v_pred-target)²` 在 (token,channel) 上 mean，loss 用 `.float()`。
- **σ 采样**：logit-normal（`logit_mean=0, logit_std=1`）→ clamp [1e-4, 1-1e-4] → **per-分辨率固定 shift**（SD3/FLUX 式 `σ'=s·σ/(1+(s-1)σ)`，**不按训练进度 ramp**）。
- **CFG**：训练 10% caption dropout（`_apply_cfg_dropout` 是唯一 dropout 点）；文字样本特例（`text_rich` → `text_rich_cfg_dropout_prob` 默认 0）+ `cfg_keep`（tag-only 永不 drop），per-sample 标志由数据线提供、已生效。

### 1.9 前向数据流（baseline 训练）
```
prompts ──encode_text──▶ input_ids[B,384] ─┐
                                            ├─embed─▶ h_und ─┐
latents/pixels ─(VAE encode)─▶ x0[B,128,h,w]│              │ 28× MoTDecoderLayer（联合注意力，
   ├─pack(patch=1)─▶ x0[B,N,128]            │              │  und 用 q/k/v/o_proj，gen 用 *_moe_gen，
   x_t=(1-σ)x0+σε ─proj_in(+t_emb)─▶ h_gen ─┘              │  gen 加 sandwich norm）
                                                            ▼
                                            proj_out(norm_moe_gen(h_gen)) ─▶ v_pred ─MSE(noise-x0)
```
采样（[generate_samples](../networks/model_mot.py)）：Euler flow（σ 1→0，同训练 shift）+ 双前向 CFG + VAE decode；**默认开 und 逐层 KV 缓存**（loop 外算一次，1.62× 加速，end-to-end 与非缓存等价）。

## 4. 消融项：开关 + 怎么跑

> **共同原则**（已落地）：默认 config 关、初始 zero-init/不构造参数 → step-0 与 baseline **逐位等价**；只加生成侧、绝不污染冻结塔。`scripts/test_arch_changes.py` 对每项有 step-0 等价断言（含 Ab2 `test_multi_layer_fusion`：关/开+gate0 均逐位等价、gate=1 后生效；Ab3 `test_und_lora_baseline_joint`：up zero-init step0 等价、lr-scale param group）。Ab3 另有 `scripts/test_ab3_ckpt_gradflow.py` 在 `gradient_checkpointing=true`（与产线一致）下复核 LoRA up/down 拿到梯度、frozen und base 无梯度。
>
> 📌 **「step-0 等价」的准确含义**：指**默认关**时 = baseline 逐位一致。**启用某消融臂后与 baseline 不同是设计意图**（如 B1 把"逐层 und"换成"独立 und→固定末层文本 cross-attend"，要测的就是这个拓扑差异本身）；消融比的是**各臂收敛后**性能、各臂从自己 init 训练，新增投影随机初始化属正常、不构成"归因污染"。臂内 zero-init（如 adapter out_proj）只保证 `num_layers=0` 与 `num_layers=2` 在 step-0 重合，使"加 adapter"可被干净归因。
>
> ⚠️ **切任何消融开关都会改变可训练参数集** → **不能 resume 旧 checkpoint**（`load_checkpoint` 会给清晰 RuntimeError）。每个消融臂用**新的 `trainer.checkpoint_dir`** 从头训。

### 4.1 消融开关总表（config 路径 + 怎么开）
所有命令在 `mot_code/mot_pilot_v1/` 下，`PY=venv-gpu/bin/python`，dotlist 覆盖：

| 消融臂 | config 覆盖 |
|---|---|
| **baseline = 真正"无 adapter"**（默认） | （无；逐层 und + **不构造 TextAdapter**/skip/abs，noise_condition=true）。⚠️ 真正的无 adapter 基线是 `text_adapter.enabled=false`（根本不建 TextAdapter 模块），**不是** num_layers=0 |
| B1 adapter·双向 | `model.text_adapter.enabled=true model.text_adapter.bidirectional=true` |
| B1 adapter·因果 | `model.text_adapter.enabled=true model.text_adapter.bidirectional=false` |
| B1 中间对照臂（**线性投影对照**：固定末层文本 + 仅 `out_proj/out_norm`，无 attention 块） | `model.text_adapter.enabled=true model.text_adapter.num_layers=0`（⚠️ **仍有可训练 out_proj/out_norm**，zero-init 起点等价但训练中学线性变换；这是"无 attention 块"的对照、**不等于无 adapter**） |
| B1 adapter·RoPE 开关（可选单列） | `... model.text_adapter.rope=true`（注：当前 `_AdapterBlock` 不加 RoPE，rope 开关尚未接线，见 4.4） |
| **Ab2 多层融合（ELMo 式末 N 层）** | `model.text_adapter.enabled=true model.text_adapter.multi_layer_fusion.enabled=true`（+ `model.text_adapter.multi_layer_fusion.num_layers=12`；⚠️ **必须同开 `text_adapter.enabled=true`**，否则构造期报错） |
| **Ab3 und_lora（理解塔顶层 LoRA）** | `model.und_lora.enabled=true`（默认 `num_layers=8 rank=32 alpha=32 lr_scale=0.3 target_modules=[q,k,v,o]`；⚠️ **不能与 `text_adapter.enabled=true` 同开**，互斥报错） |
| B2 long skip·对称全连 (LS-A) | `model.long_skip.enabled=true model.long_skip.mode=A_full` |
| B2 long skip·最外 1/3 (LS-B) | `model.long_skip.enabled=true model.long_skip.mode=B_outer` |
| B3 去噪声条件 | `model.noise_condition=false` |
| B4 绝对 sinusoidal | `model.abs_sincos.enabled=true` |

例（B1 双向臂，256 便宜消融单元）：
```bash
$PY -m torch.distributed.run --nproc_per_node=<N> train.py --config configs/stage1a_t2i_256.yaml \

```

### 4.2 逐项机制
- **B1 文本 adapter**（`TextAdapter` + `MoTAttention.forward_gen_cross`）：frozen und 末层 `H_t` → 2 层双向 transformer（RMSNorm+QK-norm+SwiGLU，**无 RoPE**，末层投影 zero-init，**~113M**；叠加逐层 `text_k/v_proj_moe_gen` ~117M，B1 臂总额外 **~231M ≈ 16% 生成塔**）→ `T_cond`；生成塔新增 `text_k/v_proj_moe_gen` cross-attend `T_cond`，**此臂下不再逐层看原始 und**。`num_layers=0` = **线性投影对照臂**：blocks 为空但**仍构造可训练 `out_norm`+`out_proj`**（zero-init→起点 T_cond≡H_t，训练中学一个线性变换），用于隔离"加 attention 块"的增益 vs "仅线性投影 + 固定末层文本拓扑"。⚠️ **它不是"无 adapter"**——真正无 adapter 是 `enabled=false`（不建 TextAdapter）；num_layers=0 仍带 ~4.2M 可训练投影参数（+ 逐层 `text_k/v_proj_moe_gen`）。比较 baseline(enabled=false) → num_layers=0 测的是"固定末层文本拓扑 + 线性投影"的合并增量，→ num_layers=2 再测"加 attention 块"的增量。
- **B2 long skip**（`LongSkipFusion`）：仅生成 token，后半对称层在 input-norm 前 `x_gen += gate·Linear(concat(RMSNorm(x_gen),RMSNorm(skip)))`，**gate zero-init→step0 等价**。A_full=对称全连(~14条)，B_outer=只连最外 ~1/3。
- **B3 去噪声条件**：`false` 时 `h_gen=proj_in(img)`（不加 t_emb），且**不构造 `time_embed`**（省参数、无孤立可训练参数）。
- **B4 绝对 sinusoidal**：仅生成 token 加 `α·Sin2D(h,w)`，α zero-init（step0 等价），AR 分桶按当前 grid 现算（不照搬 i1 方图插值）。
- **Ab2 多层融合**（`MultiLayerFusion`，命名 `multi_layer_fusion_moe_gen`）：B1 adapter 默认只吃 frozen und **末层** `H_t`；Ab2 改吃 und **末 N 层**（默认 12）的 ELMo 式可学习加权融合 `fused = h_last + gate·(Σ_i softmax(logits)_i·h_i − h_last)`，再过单 `self.norm` 喂 adapter。**logits/gate 均 zero-init**（非 one-hot）→ `fused≡h_last` → step0 与"adapter 只吃末层"逐位等价；梯度 `∂fused/∂gate=(elmo−h_last)≠0`，gate 先学、gate≠0 后 logits 拿到梯度。**强依赖 `text_adapter.enabled=true`**（仅在 adapter 臂内取多层；单独开会在构造期 `ValueError`）；`num_layers` 须在 `[1, und层数]`。融合在梯度区由 `_forward_adapter_arm` 做（gate/logits 可训）。
- **Ab3 und_lora**（`LoRAResidual`，命名 `*_proj_lora_und`）：不走 adapter 臂、留在 **baseline joint path**，给冻结理解塔**末 N 层**（默认 8）的 `q/k/v/o_proj` 各挂一条 LoRA 旁路 `Δ = (alpha/rank)·up(down(x))`（默认 rank32/alpha32→scale=1，`target_modules=[q,k,v,o]`）。原 `q/k/v/o_proj.weight` 不动（HF 加载 / und→gen 复制仍见规范键名）；`up` **zero-init** → step0 严格 no-op、与 baseline 逐位等价。**与 `text_adapter.enabled=true` 互斥**（同开 `ValueError`，Ab3 只支持 joint path）。可训练集额外纳入名字含 `lora_und` 的参数；optimizer 把 `lora_und` 参数单独划成一个 param group，`lr = base_lr × lr_scale`（默认 `lr_scale=0.3`），日志记 `lr_und_lora`。

### 4.3 消融排期（v3 + spec，先稳 baseline 再逐项）
**原计划顺序 ①B1 adapter → ②B2 long skip → ③B3 去噪声条件 →（低优先）④B4 abs-sincos**（两两正交、分开归因）。
**便宜消融单元**：256 分辨率、固定数据混合（MONET 子集 + anime 子集）、100–200K 步、bs512、信号集 DPG+PRISM(+LongText)+自建二次元。go/no-go：256 稳定涨 → 进 512，否则不为一个 trick 加复杂度。i1 已在 3B 验过的强先验（adapter 大小、去 AdaLN、long skip）当先验，只跑与我们独有变量（MoT/冻结塔/二次元域）交互的部分。

**G7 实际进展（实时状态见根目录 [当前进展_交接GPU.md](../当前进展_交接GPU.md) + `experiments/results/`）**：
- **v1 baseline / B1 / B2 / B3 单机 1×8** 跑在 `stage1a_t2i_256.yaml`（global512 / 400k 步 / LR1e-4 const+warmup300）。⚠️[待核实 2026-06-27: 各 run 当前步数/是否已收尾，以实时进展文档为准]
- **stage256 ~110–116k 首轮 eval（06-22）**：标量 loss/MSE 判不出四版（≤0.8%）→ **别用 loss 判消融**；**B1 text-adapter 在提示词/概念跟随强正向 → 暂定保留**（多指标一致、已对抗核验）；**B2 弱占优但显存最贵、B3 像免费简化**（B2/B3 已按信号停跑）。结论仍是中段·单 seed·小样本，**待 512 对齐步数 + 多 seed + 全量 DPG 复验**。
- **新设计三消融 ab1causal / ab2fusion / ab3lora 在 SEPARATE worktree** 用 `stage1a_t2i_256_v2.yaml`（2×8 多机、global1536 固定、133k 步对齐 v1 样本预算、LR1.73e-4=1e-4×√3 / warmup1000）跑。两份 256 config 隔离、绝不互喂。

### 4.4 消融相关未实现 / 注意
- **B1 兜底 Variant B**（逐生成层 zero-init LoRA 式 ΔK/ΔV）：未写。是 A 臂不明显时的退路（参数更小、保留逐层匹配）。可无数据写代码 + step0 等价测。

- **bf16 路线**：先 autocast（单卡，fp32 master）→ 纯 bf16 = FSDP2 `MixedPrecisionPolicy(param_dtype=bf16, reduce_dtype=fp32)`（多卡）。
