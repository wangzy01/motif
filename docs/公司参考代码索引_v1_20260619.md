## 0. 一句话：最对标我们的是 `nano-t2i-private`

**`nano-t2i-private`** 和我们 pilot 最像：**VAE latent flow-matching + Qwen 文本编码 + 512→1024 两阶段 + 多域 bucket 采样**（1.3B DiT + Qwen3-4B + MONET caption + SANA VAE）。其数据线（同步 bucket 采样 / per-subset timestep schedule / rank-local dataloader 诊断 / repeat_strategy）、训练循环、Qwen text encoder 接入、W&B 在线评测都可大量直接借鉴。**做数据线 / 训练细节时第一个翻它。**

## 1. 全部 19 个（按用途分组）

### 核心模型 / 训练
| repo | 一句话用途 | 对我们可参考 |
|---|---|---|
| `naifu` | 公司 FSDP2+Ulysses DiT 训练框架（**已在参考**，原始副本 `/fsx/evan/mot_code/naifu-main`） | 训练框架 / EMA（已用；迁移评估见 [naifu迁移评估与计划_v1](naifu迁移评估与计划_v1_20260619.md)） |
| `nano-t2i-private` | 极简端到端 flow-matching T2I（1.3B DiT+Qwen3-4B，两阶段，单卡 H200） | **数据线+训练+采样+caption（最对标）** |
| `arcflow-private` | 非线性流轨迹蒸馏做 2 步 T2I（Qwen-Image-20B/FLUX.1，~40x 加速） | 少步采样 / prompt embedding 分片缓存 / FSDP |
| `piflow-private` | pi-Flow 蒸馏内部变体（Qwen-Image，本地 parquet ~3.76M prompt） | 蒸馏训练工程 / grad-clip 消融 / 多节点扩展 |
| `piFlow_ReFL` | policy-based flow 蒸馏（4-8 NFE，teacher-student，LakonLab） | 高级 flow solver / **在线 eval 套件（FID/KID/IS/CLIP/VQAScore/HPSv2·v3）** |
| `dit-text-encoder` | DiT 文本编码服务（v1=CLIP+T5 / v2=Qwen2.5-VL-7B，FastAPI） | caption / Qwen-VL encoder 的模板裁剪逻辑 |
| `pixai-diffusion-runtime` | DiT-v0.3 推理服务封装（LoRA / 任务队列） | 采样推理 / 部署编排（队列、远程 text encoder、显存管理） |
| `qfty` | Qwen-Image 多模式生成 + 分布式推理工具箱（Celery worker） | EMA/LoRA 合并提取、eval harness（分片+聚合）、显存规范、分布式 worker |

### 数据 / caption / 过滤
| repo | 一句话用途 | 对我们可参考 |
|---|---|---|
| `mldatakit` | ML 数据团队共享库：数据湖(DuckDB+Polars)/队列/50+ 预配模型/tagger/embedding | **数据基础设施底座**（含美学/分类/tagger/DinoV3 嵌入；多个项目依赖它） |
| `pretrain-silver-auto` | 多源二次元数据 pipeline（Danbooru/Gelbooru/Anime-Pictures 下载+标签+S3→R2） | 数据线 / 二次元专项采集与 metadata 转换 |
| `dataset-archiver` | 分布式数据归档（FastAPI+RabbitMQ/Valkey，TAR/VIPS/DuckLake；依赖 mldatakit） | 数据线 / 队列解耦架构（与我们在线 VAE encode 思路相近） |
| `caption-refinement` | LLM+T2I 反馈循环(ReAct)迭代精化 caption（OpenRouter 多模型评审） | caption 优化流程 / 异步 LLM 调用 / visual-critique structured output |
| `caption-retrieval` | few-shot caption 检索服务（ANN+BM25 混合，danbooru 库，Jina embed） | caption few-shot 上下文（注意 ~11GB RSS，评估是否适合线上 routing） |
| `tagger-inference` | ConvNeXtV2 多标签打标服务（29K tag，torch.compile + CUDA 预处理） | 二次元自动打标 / 高效推理工程（`OPTIMIZATIONS.md` 带宽墙分析值得看） |
| `classifier_lib` | PyTorch Lightning 统一分类框架（AI检测/NSFW/风格分/清晰度） | 训练自有分类/评分器（如二次元风格分、清晰度过滤） |
| `aesthetic-score` | 美学评分 REST 服务（aes-pixai-1.2.1，动态批处理，Prometheus） | eval 阶段美学打分服务架构 |
