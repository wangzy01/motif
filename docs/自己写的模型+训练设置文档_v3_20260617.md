# Stage 1**a**

- **数据**：真实图 60–80M（MONET 为主 + GPIC 辅）+ 二次元 16M + 少量 TextAtlas（文字渲染，低优先，256 起约 3%）

- **配比**：大盘 real : anime ≈ 4:1（沿用）。注：256 阶段插入少量 synthetic / TextAtlas 后，真·real(含 GPIC) : anime ≈ 3.5:1（略偏 anime，已采纳）

- **分辨率**：课程 **256 → 512 → 1024+**，从 256 起（新增独立 256 预训阶段）。多长宽比分桶。GPIC **留在 256**（本质是 256 资产）；512+ 默认不参与，仅"短边≥512 且高美学"的小子集作 512 过渡补充。

- **caption**：**详细描述档为主**（详细 T3+T4 约 55%、其中真长 T4 约 40%）+ 中短/tag 约 45%；配比见《Caption 设计与配比》。

- **规模（相对）**：分两段——256 预训（吃大数据、把能力种下）+ 512 主训（参考 nano-T2I 512 阶段约 20 万步量级）。约 90M 数据过 1–2 遍量级；绝对步数待定。

- **可借的训练技巧**：训练时随机丢弃文本约 10%（为支持无分类器引导，Cosmos3/Qwen 都这么做）；冻结语言分支时权重衰减可设 0（参考 Lance）。

# Caption 设计与配比

- **字段选用（real，用现成 caption）**：

    - **MONET**：Florence\-2\-Large = short；InternVL3\-8B / ShareGPT4V\-7B / Gemini\-2\.5\-flash\-lite = long；`caption_original` = tag **但尽量不用**（本质是原始网页标题，噪声大、常为空）。

    - **GPIC**：tag / short / medium / long。

    - **TextAtlas**：只用 i1 开源长 caption（`caption1-5`，随机取一条）；GT 文本只作辅助字段，不当训练 caption。

    - **tag 一律优先用 GPIC 的**（比 MONET original 干净）。

    - 统一标 `caption_type`；长档截到 **~224-256 token**（按句子边界截）。注意别截到 150——gemini 中位就有 179 token，截 150 会把过半长 caption 腰斩。（2026-06-18 已上调至 ~300-340 proxy / 真 token budget 343，见实现现状指南）

- **anime**：直接用之前（团队）的 caption 体系。

- **通用**：每图每步动态选一个 caption；**全程 10% caption dropout**（支持 CFG）。**TextAtlas / 含文字样本特例**：调低甚至关其 dropout，或 dropout 时挂"含文字海报域"标签，避免被学成"无条件出字"。

- **推理改写**：不作核心依赖；可选用自带冻结 Qwen3-VL 做"短→长"自改写开关，默认关、不进评测主指标。

- **按阶段配比**：

    - **Stage1 real**（pilot 起点、可调）：T1(tag/真短) 18 / T2(短-中) 27 / T3(中长) 15 / T4(真长) 40。即详细档(T3+T4)≈55%、真长 T4≈40%（多用 gemini 全段落），tag/真短≈18% 兜裸短 prompt。

    - **daily_v1 的 1024 例外**：上面 18/27/15/40 可作为母池/Stage1 real 默认，但 daily_v1 1024 池已经审计出 T1/T4 不足；不要隐式继承，训练 config 需要 1024-specific 处理。

    - **Stage1 anime**：先以自然语言 \+ hybrid 为主，NL\-long 50 / NL\-short 20 / hybrid 20 / terms\(tag\) 10。

    - **Stage2 anime**：再提高 raw tag / danbooru tag 比例，并做 **tag\-frequency dropout**（按 tag 出现频率丢弃高频 tag），防止热门 tag 过拟合、长尾角色被遗忘。



# 预处理清晰度 \& focus\_score 过滤

> 原因：扩散/flow 模型是在回归训练目标：喂进去的图有多糊、多锯齿，出图清晰度上限就有多低；resize / 压缩 / 编码等预处理会减掉高频，而这种降质会"变成训练目标"，事后再训也补不回来。anime 的细线、硬边、网点\(screentone\) 是高频，尤其敏感（文档里 v0\.1 也专门优化过多分辨率 dataloader 来减轻清晰度 artifact）。
> 
> 

- **dataloader **：

    - 降采样用 Lanczos / bicubic \+ 抗锯齿；禁朴素 bilinear/nearest（否则线条锯齿、网点摩尔纹、硬边发糊）。

    - 不把低于目标桶的图上采样当高清（低分图路由到低分阶段或丢，见上「分辨率」）。

    - 长宽比分桶保持原比例（不非等比拉伸）、最小/居中裁、桶粒度别太粗。

    - 预处理缓存别再过 JPEG（存 latent 或无损），避免边缘 ringing/blocking。

    - VAE 编码尺寸按下采样因子对齐，注意 tiling 缝与透明通道\(alpha\)。

    - 开训前自检：抽一批预处理后的 latent 解码回像素，肉眼盯线条/网点/文字是否 crisp，确认"喂给模型的目标"本身清晰。

- **能需要为GPIC加 focus\_score/edge\-density 过滤（MONET已经比较干净）**：

    - 定义：逐图清晰度/边缘密度分（如 Laplacian 方差、Sobel/Canny 边缘占比）；高=清晰细节多，低=糊/失焦/低细节。

    - 用途：删掉天生糊的源图（失焦、运动模糊、过压、低细节涂鸦）；与美学过滤互补（"好看"≠"清晰"）。anime 要 crisp 线条，尤其需要。

    - 注意：软用、别误杀故意柔的风格（水彩/柔光/景深虚化）；最好在「最终预处理后的图」上算（同时抓源头糊 \+ 预处理糊）；成本极低，可直接当 metadata 列。  可

    

# VAE gate

> **决策已落地**：VAE gate 已拍板 **FLUX.2 Autoencoder（f16c128）**，MoT 侧 `patch_size=1`，patchify + BN 标准化已实现并 GPU round-trip 验证（见 [实现现状指南](模型架构实现现状与消融指南_v1_20260617.md) §1.6）。以下为当初做 gate 决策的**方法学/理由**（保留作设计依据）。

> 之前的文档表明，通用 VAE 的 latent 分布对 anime 域可能有明显 shift，直接拿来训生成塔有风险（分布漂移、过饱和、边缘糊）。所以接生成塔前先做一个 gate。
> 
> 

- 对 **FLUX\.2 / Qwen\-Image VAE / Wan VAE**，跑**同一批 real / anime / text\-rich\(如果有\) / hand / line\-art** 的重建。

- 指标：LPIPS、PSNR/SSIM、rFID，外加**人工看文字、线条、脸、手、边缘**。

- 统计：各 domain 的 latent mean/std、channel\-wise norm、极值、是否过饱和。

- 成本：FLUX\.2 f16c128 通道数大，重建质量好但**训练可能更贵，**一并看速度 / token 成本。

- 决策：若 anime 偏移大 → **先小规模 VAE/decoder finetune**，或**至少重算 domain\-specific latent normalization**，而不是直接拿裸 VAE 训生成塔。

## VAE

- 优先 **FLUX\.2 Autoencoder（f16c128）**，候选Wan2\.2\-TI2V VAE（f16c48）、Qwen\-Image v1 VAE （f8c16），**如果Qwen\-Image\-VAE\-2\.0开源了可以考虑换**

- FLUX\.2 注意用patchify / unpatchify、BatchNorm stats normalize / denormalize

## Attention  设计

- 文本 = causal；**理解侧干净图 = causal**；生成侧噪声图 = bidirectional。Mask 规则：噪声图能看 \[文本 \+ 干净图 \+ 全部噪声\]；文本/干净图不看噪声

- 关于理解图，主流UMM有两种mask选择：Cosmos3 = 理解图 causal，SenseNova\-U1  / BAGEL = 理解图 bidirectional。但由于我们**冻理解塔，**因此维持Qwen3\-VL 原生的causal方案。

## 归一化（QK\-norm + 生成侧 sandwich norm）

- **QK\-norm**：Qwen3 复制自带（稳 attention logits），无需动作。

- **Sandwich norm（生成侧，进 baseline）**：仅对生成/噪声 token 的生成分支，在 attn / MLP 子层**输出处**各加一个 RMSNorm 再做残差相加（`x_gen += RMSNorm(sublayer(...))`）；冻结理解侧（pre\-norm Qwen3\-VL）不碰。定位是**稳定性、不押涨分**——去了 AdaLN、又灌动态范围大的 noise/VAE latent，生成侧残差最容易涨飞，这是便宜保险（Z\-Image/CogView 产线在用）。注意它初始权重=1、非恒等，会轻微改变复制塔 step0 前向，但生成塔本就要训成生成器、无害；留 config 开关，早期不稳再关。

## 位置编码 \& Timestep 注入 \& 损失 \& CFG 等

> 本节记**设计选择与理由**；当前**确切默认值/超参表**（multiplier、各分辨率 noise-shift、optimizer 全套、text_max_length 等）以 [实现现状指南 §2 默认超参数表](模型架构实现现状与消融指南_v1_20260617.md) 为准，下文数值仅作设计意图，可能滞后。

### 位置编码

- 参考 Qwen3\-VL 的 Interleaved\-3D\-MRoPE。

- 文本退化为 1D（t=h=w），理解图像用 2D（t=0, h,w），生成图像用（t=T\_gen, h,w）

- T\_gen = max\(context\_t\) \+ Δ。参考 Cosmos3 ，加 Δ = 2048「文本→生成图像」时间索引间隔

- 生成侧 vision 段 t/h/w 在段内从 0 起（绝对段内坐标）

### Timestep 注入

- **timestep embedding：**不用 AdaLN\-Zero。timestep 走 `Timesteps(256 sinusoidal)→MLP→hidden`，加性地 scatter\_add 到噪声 token（Cosmos3里`timestep_scale=0.001`，还可以试0\.01）。

- **噪声条件去留（i1 启发）**：i1（+Sun et al. 2025）实测 flow matching 下噪声条件收益边际、删掉几乎不掉分。**baseline 维持上面的"加性注入一次"**（已实现、最稳）；**"彻底删除噪声条件"作消融项**（省参数），确认不掉分再决定是否删。**不引入 AdaLN\-zero**（与 i1/现状都背离，不值当）。

- **timestep / noise shift：**给不同分辨率不同 shift。课程从 **256 起**（256 基本不 shift），512、1024 逐步抬高。**具体数值先定 convention 再填**：i1 论文记 1024≈3.33、其代码 `train_timestep_shift`=256/512 为 0、1024 为 0.3（同一量、不同 convention，**不可直接照搬**）；按我们实现的 shift 公式映射后填等价值（乘式 convention 下 1024 试验起点 ~4、sweep 3.3–5，随最终 VAE 下采样因子调）。

### 损失

- v\-prediction \+ rectified flow\-matching \+ 纯 MSE

- 如果有统一训练（含理解 CE）时，CE:MSE ≈ 0\.1:1（参考U1）

- VAE latent 必须做 channel\-wise normalization 或使用对应 VAE config 中的 latent mean/std。Qwen\-Image v1 VAE config 已带 `latents_mean/std`；FLUX\.2 AE 也应按官方 pipeline 的 scaling/shift 处理，不要直接裸 latent 训练。

### CFG等

- 10% text dropout（Cosmos3/U1）。

- **优化器（采用 i1 配方）**：Adam β=(0\.9, 0\.95)、lr 1e\-4 **constant**、**wd=0**（frozen LM 下）、grad clip 1\.0、EMA 0\.9999；保留**短 warmup**（几百步）防早期不稳。constant LR 对多阶段续训更省心（i1 + Lance 双重背书），替换旧的"warmup + 线性衰减到 30%"计划。

- 推理先用标准双前向 CFG；后续如果吞吐紧张，再做 CFG parallel / distillation。

- 如果要做RLHF，可以用 Qwen\-Image\-2 的**混合 CFG**（仅在采样 rollout 启用 CFG，策略优化时丢掉无条件分支，省一次前向）

## 文本 adapter（上游双向，架构消融第 1 项）

为什么我们特别需要：我们的 MoT 里文本走冻结 Qwen3-VL，**生成塔逐层 attend「对应层」und 的 K/V**——文本侧对生成塔零可训练整形通道。i1 证明"加大 adapter ≈ 多接 encoder"；对我们更关键：adapter 是文本信息**唯一**可学习的整形通道，预期收益比 i1 更大。

选定接法（上游双向 adapter，贴 i1 + 双向 trick）：

1. 跑完冻结 und，取**末层** hidden `H_t [B, L_t, 2048]`。
2. 过一小块可训练**双向** transformer：2 层、宽 2048、RMSNorm + QK-norm + SwiGLU、**不加 RoPE**、**末层投影 zero-init**（起点 ≈ 原始文本，纯增量）；~~约 35M，<2.5% 生成塔~~ → **更正（实测真 config）：B1 臂额外 ~231M（adapter ~113M + 逐层 text K/V ~117M）≈ 16% 生成塔**，原 35M/<2.5% 估算偏低（见实现现状指南 §3 B1 行）。
3. 生成塔用**新增可训练 text K/V 投影**（`text_k/v_proj_moe_gen`）attend 这份整形后的 `T_cond`；**此臂下生成塔不再逐层看原始 und**。理解分支仍用原始 `H_t`，互不污染。

- **双向**：Qwen3-VL 是 decoder-only、文本因果；双向重编码针对性回填 i1 "encoder-decoder 双向 > decoder-only" 那段 gap。
- **不加 RoPE**：`H_t` 已带 LM 内部位置信息，再叠多半冗余；RoPE-in-adapter 作独立小开关、单列一格，不和"是否双向"混进同一轮。
- **兜底 Variant B**（A 不明显再退）：逐生成层给文本 K/V 加 zero-init LoRA 式 ΔK/ΔV，参数更小、保留逐层匹配。
- **消融主轴**：`{无 adapter} vs {A·因果} vs {A·双向}`，RoPE 全程关。
- ~~**不设中间对照臂（已定）**~~ → **决策已反转**：实现时**单列了中间对照臂**（`text_adapter.num_layers=0` = 线性投影对照臂，固定末层文本 + 仅 `out_proj/out_norm`、无 attention 块），用于把"加 adapter 块"的增益与"拓扑改动 + 线性投影"分开归因（覆盖此处 v3 原"省算力不单列"，见实现现状指南 §4.1/§4.2 与决策记录）。原顾虑（归因模糊）正是单列对照臂要解决的。
- 可选诊断：T5Gemma-2B 条件纯 T2I 对照，量化"冻结 Qwen3-VL 当文本源亏多少 + adapter 补回多少"，给"为什么不用最优 text encoder"备好自家数字。

## 生成侧 long skip（消融项，排 adapter 之后）

i1 Finding 2：U-ViT 跨深度捷径，跨宽度/跨 backbone 稳定涨分，尤其 DPG/文字；附录"完全对称（深度29→层1-14）"≥ 所有变体。现代 DiT 多丢了这个设计。我们只做生成侧、zero-init 版以保 baseline。

- **LS-A（主，仅生成 token）**：前半层存激活，后半对称层（i ↔ L+1−i，L≈28 → ~14 条）在生成分支 **input-norm 之前**融合：
  `x_gen += gate · ZeroInitLinear(concat(RMSNorm(x_gen), RMSNorm(skip)))`。
  gate **zero-init → step0 严格等价无 skip**；concat 前各自 RMSNorm 压浅/深层尺度差（比 i1 原版 replace 形更稳）。只动生成 token：非对称 mask 保证不回流污染冻结侧、只缓存生成 token 激活省显存、绕开 AR/KV-cache（去噪是非自回归前向）。
- **消融（≤3 组）**：baseline / LS-A（对称全连）/ LS-B（只连最外侧 ~1/3 层，砍显存、判断收益是否主要来自最长 skip）。go/no-go：256 稳定涨 → 进 512；否则不为一个 T2I trick 给主干加复杂度。

## 绝对 sinusoidal 位置（可选，低优先）

主线保留 Interleaved-3D-MRoPE（承重墙）。i1 的"绝对 sinusoidal + RoPE"只作可选消融：仅生成 token 加 `α·Sin2D(h,w)`、α zero-init、**AR 分桶感知**（不照搬方图插值），且只在文字渲染/精确版面成为明确目标时才跑；不动文本/理解侧。
