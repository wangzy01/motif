# MoT 采样权重 spec v1（real 池：MONET-real + GPIC）

更新：2026-06-16。配套 config：`mot_code/data_analysis/configs/t5_sampling_weights_v1.json`；参考实现：`mot_code/data_analysis/scripts/t5_sampling_weights.py`。

> **定位**：本 spec 只管 **real 池内（MONET-real + GPIC）的采样权重 + 分辨率路由**，是"指针模型、权重不烘焙进 manifest"的训练侧配方。
> 跨域大盘混合（real : anime : synthetic : TextAtlas）是**上层 mixer**（见 §6 骨架），需要 anime（团队）、synthetic（已建 `synthetic_v1`）、TextAtlas（本轮缓）的 manifest，本 spec 只填 real 部分的槽。
> 与两份 v3 doc（《模型+训练设置 v3》《数据集 v3》）对齐；如有出入以本 spec + 后续拍板为准。
> ⚠️ **daily_v1 例外提醒（2026-06-17）**：21M 日常探索版是母池子集，1024 阶段不要直接套本 spec 的 `18/27/15/40` 无重采样假设。daily_v1 1024 可用池审计：T1/T4 oversample_factor=**1.202 / 1.949**；训练配置需显式处理。
> ⚠️ **256 配比修订（2026-06-17）**：实际训练线 complete_v1（daily+anime）stage-256 的 real 内 **MONET:GPIC 改用 11:7**（= 静态池 11M:7M 自然比，monet_real 0.397 / gpic 0.253），**取代本 spec 多处写的 80:20**。本 spec 的 80:20 是**母池/daily 的默认**配方；complete_v1 集成见 AAA 交付文档 §11.5 + `configs/t5_sampling_complete_v1.json`。（下文 §1/§2/§6/§7/§9 凡写 80:20 处均指母池默认，complete_v1 一律读 11:7。）
> ⚠️ **第 5 个注入域 textatlas（2026-06-26+）**：complete_v1 现有 5 个域——本 spec 的 4 域（anime + real/synth：MONET-real/GPIC/synthetic）之外新增 **textatlas**（i1 开源长 caption 文字渲染数据，**注入域、同 synthetic 不分档**）。它**不改本 spec 的 band-first 机制**——band-first 只管 real 池内（MONET-real+GPIC），textatlas 像 anime/synthetic 一样只占一个 domain_mix 槽（5 域 domain_mix、mix 机制修复、TextAtlas 接入全见 [complete_v1_dataline_设计与变更_v1_20260627.md](complete_v1_dataline_设计与变更_v1_20260627.md)）。

## 0. 用到的 manifest 字段（`t5_manifest/rich_v1`）

`dataset`(gpic/monet) · `sub_source`(laion/coyo/commoncatalog-cc-by/cc12m/megalith10m/diffusion-aesthetic-4k/gpic) · `width/height` · `res_bucket`(256/ge512) · `aes`(+`aes_scorer`) · `cluster_id`(0..19999) · `dominant_cat` · `caption_tier`(GPIC 1-4；MONET 0) · `has_t1..4`(该图能服务哪些档) · `tok_i1`(GPIC i1 token 数) · `tok_{original,florence,internvl,sharegpt4v,gemini}`(MONET 各 captioner token 数) · `caption_type` · `synthetic/holdout`。

## 1. 核心采样过程（**档位优先 / band-first**，精确命中 18/27/15/40）

每抽一个训练样本，在 stage `s` 下：

1. **抽档** `b ~ BAND_MIX[s]`（real 域默认 `T1 0.18 / T2 0.27 / T3 0.15 / T4 0.40`）。档位配额由这一步**精确保证**（供给审计已确认每档 oversample_factor<1、子集即可，无需重采样）。
2. **抽域** `d ~ DOMAIN_MIX[s]`，仅在"对档 `b`、stage `s` 有合格图"的域上归一（如 512 阶段 GPIC 基本退场、1024 阶段只剩 MONET≥1024）。real 域内 256 阶段 `MONET:GPIC = 80:20`。
3. **抽图**：在 `(d, b, s)` 合格集合里，按权重 `w(i) = source_factor(i) × cluster_factor(i)` 抽一张图（见 §3、§4；**不按 aes 加权**，Evan 定）。
4. **取 caption**：按 §5 的 band→captioner 策略选具体 caption 文本并截断。
5. **caption dropout**：全程 10% 置空（支持 CFG）；含文字/海报样本特例（§5）。

> band-first 的代价：能服务多档的图（MONET 多为 2-4 档）总曝光略高于单档图。real 池里这接近均匀、可接受；v1 不做逐图曝光约束（列为已知 caveat）。

## 2. 分辨率路由（各 stage 的"合格集合"，对齐 v3 课程 256→512→1024+）

| stage | GPIC | MONET-real | 说明 |
|---|---|---|---|
| **256** | 全部合格（256 桶 + ge512 可降采到 256） | 全部合格 | GPIC 主场；real 内 MONET:GPIC=80:20（母池默认；complete_v1 用 11:7，见顶部 banner / AAA §11.5）|
| **512** | **0（默认退场，以此为准）**。可选过渡/消融子集 = `res_bucket==ge512 且 aes≥AES_GPIC512`（p75≈5.57），但 `monet_real_gpic_ratio.512=[1,0]` 令其**默认权重 0**；eligibility 仅备开启用，**不要只解析 resolution_routing 就放 GPIC 进 512** | `res_bucket==ge512`（约 32.0M） | GPIC 退场；MONET 主导 |
| **1024** | **≈0**（GPIC 短边≥1024 几乎没有；不上采样） | `min(width,height)≥1024`（约 8-9M，主要 commoncatalog） | + synthetic_v1（上层 mixer 注入，1024 主力高清） |

**铁律**（v3 doc）：不把低于目标桶的图上采样当高清；GPIC 不进 1024；降采样用 Lanczos/bicubic+抗锯齿。

## 3. 源权重（laion/coyo **适度拉平**，Evan 定）

幂律温度 `α`（`SOURCE_ALPHA`，默认 **0.5**）：每图源因子 `source_factor(i) ∝ N_source(i)^(-α)`，则**源级质量 ∝ N_source^(1-α)**。
- `α=0` 自然（laion+coyo 占 MONET 源 68%）；`α=0.5` sqrt 温和；`α=1` 各源等质量（满拉平）。
- GPIC 单一源，`source_factor≡1`（GPIC 占比由 §2 的 80:20 域因子控制，不在源因子里）。
- **实测（dry-run，含 band-first+80:20 域+簇拉平，of-total@256）**：α=0.5 → laion+coyo **46.6%**（自然 α=0 约 54%、满拉平 α=1 见 §9 sweep）。注：之前"54%"是"仅 MONET 源内"的口径，叠上 GPIC 20% 域占比后 of-total 更低。

> ✅ **已定 `α=0.5`（Evan 2026-06-16）**。实测 laion+coyo 46.6% / da4k 0.7% / 簇最散。`α=1`（满拉平）已验证为**病态**（da4k 1.17 万张微源被抬到 14%），故区间锁 [0.3,0.7]、取 0.5。见 §9。

## 4. 簇权重（**温和按簇拉平**，Evan 定）

幂律 `β`（`CLUSTER_BETA`，默认 **0.5**）：`cluster_factor(i) ∝ cluster_size(cluster_id_i)^(-β)`。
- `β=0` 自然；`β=0.5` ~1/sqrt(簇大小) 温和拉平；`β=1` 每簇近似等曝光。
- 选样阶段已对大簇 water-fill 削过冗余（最大簇仅占 0.045%），故采样侧温和即可。
- 内容类目（render/3d 占 26%）**不单独设目标**：靠簇拉平间接吸收（render/3d 散在多簇，β>0 自然压其总曝光）。`cluster_id==-1` 的（仅 synthetic_v1）回退 `cluster_factor=1`。

## 5. band → captioner 取数策略（对齐 v3 doc《Caption 设计与配比》）

抽到档 `b` 后，为该图选具体 caption：
- **GPIC**：用其 i1 caption（`caption_type`∈tag/short/medium/long，落 `caption_tier`）。GPIC 只会在它自己的 tier 档被抽到。**干净 tag 优先用 GPIC 的**。
- **MONET**：按档选 captioner（用 `tok_*` 判断哪个 captioner 落档 `b`，按优先级取第一个落档的；**优先级是软偏好**，下列都取不到时 **fallback 到任意"`tok_*` 在档 `b` 内且 `>0`"的 captioner**。⚠️ **band 合格性以"存在 tok>0 且落档的 captioner"为准，不能只信 `has_tb`**：已发布 manifest 有 **13 行 `has_t4=1` 但唯一 T4 captioner（gemini）因 int16 溢出成负**、无可用 T4 caption——这类行**不得进入该档**（无落空、无负值 caption）。Evan 2026-06-16 定）：
  - **T4 (≥129)**：`gemini → sharegpt4v → internvl`（真长段落，多用 gemini）。
  - **T3 (65-128)**：`internvl → sharegpt4v → gemini`。
  - **T2 (25-64)**：`florence`（**megalith 用 florence 首句 ≤64 tok**）`→ original`。
  - **T1 (≤24)**：`original`（网页 alt-text，噪声大，**有意保留**练真实裸短 prompt 鲁棒）；干净 tag 主要由 GPIC 出。**commoncatalog/megalith 无 T1**（has_t1≈0），抽到回退到 GPIC/其他源。
  - 清洗：internvl 删末尾不完整句子。
- **synthetic（synthetic_v1）**：用生成 prompt（中等长度，天然落中档）。
- **长档截断**：~**224-256 token** 按句子边界截。**不要截 150**（gemini 中位 179，截半）。（2026-06-18 已上调至 ~300-340 proxy / 真 token budget 343，见实现现状指南）
- **dropout 特例**：含文字/海报域（text-rich、TextAtlas）调低甚至关 dropout，或 dropout 时挂"含文字海报域"标签，避免"空 caption→硬出字"。

> 实测覆盖（QC）：MONET sharegpt4v 97.4% / gemini 78%（v3 doc 写~90%，实际 78%，仍足够撑 T4：目标 24M、gemini 池 31M）/ florence 99.4% / internvl 89% / original 78%。megalith 99.5% 是 T3/T4、几乎无 T1/T2；commoncatalog 仅 2% T1、27% T4——取数回退按上面规则。

## 8.5 loader 边界规则（独立审计后定，Evan 2026-06-16）

loader/spec 级规则（不重建 manifest，用 loader 兜；脚本已为未来重建修正）：

0. **⚠️ 图像源 = `.tar` 全分辨率，不是 parquet `thumbnail`**（已查证）：MONET parquet 的 `thumbnail` 只是 ≤384px 预览；全分辨率 JPEG 在同名 `.tar`（webdataset，挂载已有）。读图：MONET/synth = `{src_root}/{src_shard .parquet→.tar}` 成员 `{src_key}.jpg`；GPIC = `{src_root}/images/train/{src_shard}/{src_key}.{ext}`（**扩展名混合 ~88% .jpg + ~12% .png，别硬编码 .jpg**；权威路径用 `parquets/gpic_train_{src_shard}.parquet` 的 `s3key` 列）。实测 `.tar` 图尺寸 = manifest `width/height`（分辨率课程/synthetic-1024 成立）。**用 thumbnail 训练只有 384px、毁掉 512/1024。**
1. **holdout 全局排除**：`holdout==1` 在**任何池都不进训练**。real(`rich_v1`) 已在选样阶段排净(=0)；**`synthetic_v1` 当前仍带 6,565 条 holdout 标记**（建池早于本决策）→ **loader 必须 `filter(holdout==0)`**，real+synthetic 一视同仁。`t5_build_synthetic_manifest.py` 已加 `& holdout==0`，下次重建即干净。
2. **caption fallback + band 合格性以 tok 为准（不是 has_tX）**：band→captioner 优先级是软偏好；优先级取不到时 fallback 到任意"`tok_*` 在该档且 `>0`"的 captioner。**band 合格性 = 存在 tok>0 且落档的 captioner**；不能只信 `has_tX`/`cap_*`（已验证：已发布 manifest 有 **13 行 `has_t4=1` 却无任何正 T4 token**，溢出所致）。这些行抽样时自然排除该档。
3. **token 计数 ≤0 视为该 captioner 不可用**：脚本已把 `tok_*` 改 `int32`+clip≥0（彻底修复）；但**已发布的 `rich_v1` 仍是 `int16`、有 18 个负 token（17 `tok_gemini` + 1 `tok_original`）** → loader 见 `tok<=0` 当该 captioner 不可用。其中 **13 行的负 token 是该行唯一的 T4 captioner** → 这 13 行**无可用 T4**、不进 T4（其余档/其余行不受影响）。下次重建即无负值。
4. **GPIC@512 = 0**：512 阶段 GPIC 完全退场（doc 一致，GPIC 是 256 资产）。`monet_real_gpic_ratio.512=[1.0,0.0]`，**以此为准、不要只解析 `resolution_routing`**。要做过渡/消融再改成如 `[0.97,0.03]`（eligibility 已算好）。
5. **aes 缺失（null 或 NaN）统一兜底**：MONET real 有 **5,468 个 aes 缺失**（parquet 里可能存为 null 或 NaN，loader 两者都当缺失）。本 spec 不按 aes 加权 → 无影响；若他处用 aes，给中位兜底或排除，别让 NaN 传染统计。
6. **source/cluster 因子用全局 60M 统计**：`N_source`、`cluster_size` 在**整个 60M real 池**上各统计一次，**不要**在每 shard / 每 band / 每 stage 子集内重算（否则权重口径漂移）。参考实现 `t5_sampling_weights.py` 即全局算一次。
7. **`domain_mix` 是占位且未归一**（256 之和 0.98，因 anime/TextAtlas 待接）：loader 须**显式归一**后使用，别静默接；接入真实 anime/TextAtlas manifest 时一并定稿。

> 审计另建议「最终 loader 实现后做一次真实 100 万抽样 end-to-end dry-run（含跨域 mixer、统计 captioner 实际取数失败率、holdout 泄漏、单图 repeat top-k）」——同意，属 **loader 落地后**的步骤，记给训练侧。

## 9. dry-run 验证（job `evan-mot-t5-wcheck-*`，`rich_v1/sampling_weights_check.json`）

期望抽样分布（精确算 P(i)，非采样）证实 spec 落地：
- **band 配比精确命中** 18/27/15/40（各 stage `P_total=1.0`）。
- **256 域 = MONET:GPIC 80:20**（精确）。
- **1024 = commoncatalog 主导（57%）**、cc12m→0（短边不够）——对齐 v3 doc"MONET 短≥1024 主要 commoncatalog"。
- **簇拉平生效**：256 最大簇仅 0.019%，有效簇数 ~14.5k。

**`source_alpha` 实测对比（stage256，of-total real 抽样占比）**：

| α | laion+coyo | da4k | 有效簇数 | 评价 |
|---|---|---|---|---|
| 0.0 自然 | 57.1% | 0.03% | 13,405 | 爬虫源主导 |
| 0.3 | 51.1% | 0.18% | 14,068 | 轻 |
| **0.5（默认）** | **46.6%** | 0.7% | **14,481** | 适度，簇最散 |
| 0.7 | 41.4% | 2.4% | 14,738 | 偏强 |
| 1.0 满拉平 | 30.0% | **14.0% ⚠️** | 11,881 | **过头**：把 11,688 张 da4k 微源抬到 14%（每图重复~千次）、簇多样性反降 |

> **结论**：α=1（"各源等质量"）因 da4k 是微源（仅 1.17 万张）而病态——满拉平会把这 1.17 万张图重采到 14%。合理区间 α∈[0.3,0.7]，默认 **0.5**（laion+coyo 46.6%、da4k 仍仅 0.7%、簇最散）。若想更强压爬虫源，建议 α=0.7 而非 1.0，或加"每图过采样上限"护栏（防微源爆掉）。

## 8. 已知 caveat

1. band-first 下多档图（MONET 多为 2-4 档）总曝光略高于单档图；v1 不做逐图曝光约束。
2. **daily_v1 21M 子集的 1024 阶段 caption 供给绑定**：daily_v1 1024 可用池=5,049,529，T1/T4 oversample_factor=**1.202 / 1.949**。若用 daily_v1 训练 1024，不要把 `band_mix_real=18/27/15/40` 当作无重采样可行；必须在训练 config 里显式处理。
3. synthetic `cluster_id=-1`、`dominant_cat=unknown`（未进联合聚类）→ 簇拉平对它回退为 1；它是 1024 锚池、不靠簇均衡。
4. da4k(11,688) 44% 无 jasperai aes（图是真实超高清，仅未打分）；不按 aes 加权时无影响。
5. 跨域 anime/TextAtlas 数值是 v3 doc 占位，接入真实 manifest 前不要当定稿。
6. **da4k 在 1024 阶段过采样偏高**：dry-run 中 real-1024 的 da4k 占 6.72%，但只有 11,688 张实图 → 单图 repeat 偏高。可接受（da4k 是 24MP 优质实图）。**Evan 定（2026-06-16）：先监控**（e2e dry-run 看单图 repeat top-k），过拟合再加"微源每图过采样上限"护栏。
7. **synthetic 含文字/水印样式**：1024 阶段 synthetic 占上层 mixer ~18%，其中部分生成图带明显文字/水印/海报版式。1024 训练时**监控无提示出字、签名水印、版式漂移**（按长宽比分桶看），异常则降 synthetic 占比或挂"含文字域"标签。
