## Read So Far

- The existing rd256 diagnostic set shows the suspected failure clearly:
  top/head and bottom/foot truncation both appear often, including full-body and
  multi-person prompts.
- Stage512a G1 already looks materially better on this directional slice:
  head cuts drop sharply and full-ok cases increase.
- Foot truncation remains the main residual issue in G1, especially for dynamic
  standing poses and multi-person/full-body prompts.
- Prompt emphasis helps score quality modestly, but the G1 tag-vs-NL+emphasis
  split does not show a categorical cure by itself. This supports the plan to
  judge the real fix using multi-AR/latest training rather than prompt wording.
